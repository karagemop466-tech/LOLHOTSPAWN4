Reverse-Engineering Hotspawn Pick'ems & 4–8 Hour Automation Architecture CRON: EVERY 6 HOURS (00:00, 06:00, 12:00, 18:00 UTC)

To keep all League of Legends Pick'em probabilities, match locks, and originated regional lines continuously updated within the required 4–8 hour window, we reverse-engineered Hotspawn's dual-stack architecture and implemented an automated GitHub Actions pipeline (.github/workflows/update-pickems.yml + scripts/update_pickems.py).

1. Reverse-Engineered Hotspawn Endpoints & Architecture

Endpoint / Surface URL Pattern Authentication & Payload Structure Role in 4–8h Pipeline
LoL Pick'em SSR Lobby https://play.hotspawn.com/lol-pickems Public SSR HTML containing all active id="pickem-card-<id>" DOM cards, tier/tournament filter counts, point badges (30/20/10 PTS), EDT/EST timestamps, and crowd pick %. Primary source of truth for which LoL fixtures are currently open for user picks in the Pick'em lobby.

Hotspawn UTC Match Feed & Tournament Pages https://www.hotspawn.com/matches SSR HTML with exact UTC timestamps and canonical match slugs (/matches/<slug>-<id>). Verifies exact UTC start times (resolving US EDT/EST Daylight Saving shifts on Nov 1) and canonical URLs.
Leaguepedia Raw Data API https://lol.fandom.com/wiki/Data:<Tournament>?action=raw Structured MediaWiki {{MatchSchedule}} templates with game scores, points, Riot platform game IDs (LOLTMNT05_*), and forfeit/DQ footnotes. Feeds our Bradley-Terry / Log5 origination engine for all 202 low-tier regional LoL matches.

2. Automated 6-Hour Update Workflow (.github/workflows/update-pickems.yml)

Our GitHub Actions workflow executes automatically every 6 hours (cron: '0 */6 * * *' — within the 4–8 hour target window) as well as on every push to main and manual workflow_dispatch: 

name: Update Hotspawn LoL Pick'ems & Deploy Pages
on:
  schedule:
    - cron: '0 */6 * * *'   # Runs every 6 hours (4-8h window)
  workflow_dispatch:
  push:
    branches: [ main ]

 jobs:
  update-and-deploy:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pages: write
      id-token: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Run Hotspawn LoL Pick'ems Scraper & Origination Engine
        run: python3 scripts/update_pickems.py
      - name: Commit Updated Dataset & Dashboards if Changed
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          if ! git diff --quiet; then
            git add data/ *.html assets/
            git commit -m "chore(auto): refresh Hotspawn LoL Pick'ems probabilities and site"
            git push origin HEAD:main || true
          fi
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
      - uses: actions/deploy-pages@v4

Methodology & Non-Hallucination Guarantee: Hotspawn community pick percentages (hs_pct) are never used as an indicator of win probability. Featured matches use de-vigged multi-bookmaker & Polymarket consensus odds; low-tier regional matches use originated Bradley-Terry / Log5 probabilities derived strictly from official Leaguepedia match & game records. Unverified TBD bracket slots are left blank and flagged.
